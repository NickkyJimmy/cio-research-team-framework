# Edge Cases

How to handle non-standard situations during instrument design. Each scenario describes the problem and the recommended approach.

---

## Plan has more than 5 content blocks

Group related blocks into combined sections to keep instrument length manageable. Flag to stakeholders if the instrument exceeds the mode's time limit even after grouping.

---

## Mixed methods (Qual + Quant)

Produce both instruments. Add a handoff note explaining what qualitative findings should inform quantitative question refinement (or vice versa). Specify sequencing: which method comes first and why.

---

## Plan specifies methodology but not specific mode

Default to CASI for Quant (if online reach is viable) and IDI for Qual. Flag the assumption with the Vietnamese label: **"[GIẢ ĐỊNH — cần xác nhận]"**.

---

## Stimulus materials not yet finalized

Create placeholder sections with the Vietnamese label: [TÀI LIỆU KÍCH THÍCH: description]. Mark as "chờ hoàn thiện" (pending completion) in metadata. Proceed with question structure around the placeholder.

---

## Very short timeline (less than 1 week)

Prioritize screener + core objective sections. Mark nice-to-have sections with the Vietnamese label: **"[TÙY CHỌN — nếu còn thời gian]"** (optional — if time permits).

---

## Sensitive questions (financial behavior, income)

Place late in the instrument (after rapport is established). Use ranges instead of exact numbers. Add a reassurance statement in Vietnamese: *"Thông tin của bạn được bảo mật hoàn toàn và chỉ sử dụng cho mục đích nghiên cứu."*

---

## Target audience includes non-MoMo users

Adapt language to not assume MoMo familiarity. Add product/feature explanation text before evaluation questions so non-users have enough context to respond.

---

## Stakeholder insists on biased question wording

Flag the issue respectfully with evidence of how the bias affects data quality. Propose a neutral alternative. If stakeholders still insist, include their version with a Vietnamese annotation: **"[LƯU Ý: Câu hỏi này có thể gây thiên lệch. Xem giải thích.]"**

---

## Instrument needs to work in multiple modes

Create a master version (CASI) with full complexity. Then produce mode-adapted variants with specific adjustments noted per mode. See the mode-adaptation reference for constraints per mode.

---

## Tracking study — new wave

Follow the tracking study protocol. Preserve all benchmark questions verbatim. Add new questions in a separate section marked with **"[MỚI — Wave N]"**. See the tracking-study reference for full details.

---

## Content framework is incomplete or informal

Help the user structure it into the standard hierarchy (Objective → Sub-objective → Content Block → Measure → Dimension → Indicator) before proceeding. Use the traceability matrix as a collaborative structuring tool.

---

## User provides content framework in English

Map it as-is for traceability, but produce all respondent-facing questions in Vietnamese. Keep content block names in their original English for traceability alignment.
