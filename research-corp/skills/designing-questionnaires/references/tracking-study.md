# Tracking / Multi-wave Study Protocol

For multi-wave or tracking studies, additional rules apply to maintain data comparability across waves. Violating these rules compromises trend analysis and makes wave-over-wave comparison unreliable.

---

## 1. Benchmark Questions (Tracked Items)

- **NEVER** change the wording of tracked questions between waves
- **NEVER** change the scale or response options
- **NEVER** change the question order relative to other tracked items
- Document any context changes that might affect responses (e.g., market events, competitor launches, seasonal effects)

---

## 2. New Questions Per Wave

- Add new questions **AFTER** the tracked items section
- Or create a separate "Wave [N] supplement" section
- Mark new questions clearly with a Vietnamese label: **"[MỚI — Wave N]"**

---

## 3. Retired Questions

- Questions to be removed should be marked one wave in advance: **"[SẼ XÓA — Wave N+1]"**
- Keep one transition wave where the question is still asked but not mandatory (enables overlap analysis)

---

## 4. Wave Metadata

Record the following for every wave:

- Wave number and date
- Changes from previous wave (additions, removals, modifications)
- Known external factors that may affect comparability
- Fieldwork period and sample composition

---

## 5. Instrument Versioning

- Name format: `[Project]_[Mode]_v[Wave].[Revision]`
- Example: `MoMo_PayReceive_CASI_v3.1`
- Keep all previous versions archived for reference and audit
